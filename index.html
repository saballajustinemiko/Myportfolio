Programming Background: C++ Loop Statements

In our C++ programming lessons, we studied control structures including for loops and while loops which I used in my Grade Calculator project:

1. C++ For Loop Example

#include <iostream>
using namespace std;

int main() {
    for(int i = 1; i <= 5; i++) {
        cout << "Subject " << i << " Grade Loaded." << endl;
    }
    return 0;
}

2. C++ While Loop Example

#include <iostream>
using namespace std;

int main() {
    int choice = 1;
    while(choice == 1) {
        cout << "Grade Calculator Active." << endl;
        cout << "Enter 0 to exit: ";
        cin >> choice;
    }
    return 0;
}
